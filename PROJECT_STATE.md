### [2026-07-17] - Final-Answer Evidence Barrier + Atomic Cross-Product Durability
- **WHAT**: Audited the live finalization path after the cross-account telemetry proof and found two independent races: the current answer was not sent into the full background pipeline when that same answer triggered completion, and `start_finalization_background()` marked the session in-flight before its worker called `end_session()`, allowing the worker to wait on itself. Production correctness requires an evidence barrier before evaluation and one atomic database boundary for the report plus delivery intent.
- **IMPACT**: The terminal answer now contributes history, weakness/discrepancy/reasoning facts, per-answer score, and telemetry before the final evidence packet whenever it completes within the configured 120-second bound. If it does not, recruiters see an explicit warning and `late_turn_analysis` remains untested. Immediate callback failure is safe because the committed outbox row is retried idempotently. A cross-product interview returns `503` without consuming its launch token when required durability tables are unavailable.
